## 一、论文结构与叙事

### 1.1 缺少 Related Work 章节

目前论文从引言直接跳到方法，缺少专门的文献综述。对于授课硕论文，这是一项重大缺失。建议增加一节，至少覆盖：

- **Reward Hacking / Reward Misspecification**：Amodei et al. (2016) 在参考文献[1]中引了但正文未讨论。应综述 reward hacking 的经典案例（如 CoastRunners 的"绕圈刷分"、游戏 AI 中的 unintended behaviors）。
- **稀疏奖励 RL**：HER、curiosity-driven exploration、intrinsic motivation 等方法。
- **GRPO 的提出与应用**：GRPO 最初是为 LLM 的数学推理提出的（DeepSeekMath），在 continuous control 上的 adaptation 是本文的重要贡献，应明确讨论与原始 GRPO 的差异。
- **Group-based / Population-based RL**：与 GRPO 机制相关的 prior work。

### 1.2 引言可以更聚焦

§1.1 的 Sim2Real 和长程操作两个场景描述很好，但§1.2 直接跳到 PPO vs GRPO 的机制对比，中间缺少一个"问题陈述"段落：**明确写出本文要回答的核心 research question**。目前 Q1–Q4 在§3.2 才出现，太靠后了。建议在引言末尾就列出。

### 1.3 "方向 vs 幅度"论述需要更精确

这是论文的核心贡献点（§1.3 第 2 条），但当前表述存在一个细微问题：

- PPO (Misaligned) KL = 25.4 nats，GRPO (Misaligned) KL = 19.4 nats
- 比值 1.31×，说"同一数量级"没问题
- 但 31% 的差距是否被视为"幅度的差异"？审稿人可能会追问

建议改为更精确的表述：

> **"GRPO 的策略更新幅度与 PPO 处于同一数量级，但远小于两者行为差异所暗示的差距——PPO 的 return 变化是 GRPO 的 5.6 倍（+181 vs -32），而 KL 散度仅差 1.31 倍。这说明 PPO 的额外更新幅度主要集中在少数与 reward hacking 相关的维度上，而非整体策略的大幅偏离。"**

### 2.2 模型选择标准的 bias

使用 `best_by_reward` 选择 PPO 和 GRPO 的模型。但 PPO 的 reward 被 reward hacking 人为抬高，这意味着在**选择 reward hacking 最严重的 PPO checkpoint** 来评估。这实际上对 PPO 不公平——如果选 `best_by_success` 的 PPO 模型，结果可能不同。

建议：(1) 同时报告两种选择标准下的结果；(2) 在正文中讨论这一选择 bias。

### 2.3 缺少关键消融实验

对于授课硕论文，以下消融实验可以显著增强说服力：

| 消融 | 目的 | 难度 |
|------|------|------|
| **Group size K** | 直接验证 group-relative advantage 的机制 | 中（需重新训练 3-4 个 GRPO 变体） |
| **PPO + reward normalization only** | 排除"GRPO 只是做了 reward normalization"的替代解释 | 低（只需加一个 PPO variant） |

其中 **PPO + reward normalization** 是最关键的对照——VecNormalize wrapper 已经对 reward 做了 normalization（`norm_reward=True`），那 PPO 理论上应该已经看到归一化后的奖励。如果 PPO 在这种情况下仍然 reward hack，说明问题不在于 reward 的绝对尺度，而在于**优势估计的信号结构**。这个对照可以大大强化机制论证。

### 2.4 KL 散度估计的分布偏差

在§4.2 中诚实地讨论了这个问题，但建议将其提升到正文中更显眼的位置。当前只在局限性中一笔带过，但这个问题可能影响核心结论：

> 如果 PPO 将机器人带到 baseline 从未去过的状态（如极端门操控），那些 OOD 状态上的 KL 才是最大的，但采样完全覆盖不到。

建议增加一个分析：**记录 PPO 和 GRPO 评估过程中机器人躯干 x 坐标的分布**，展示 PPO 的状态分布确实偏离了 baseline 的分布。这既是对 OOD 问题的佐证，也是 reward hacking 的另一个行为证据。数据可以从 `results/reward_decomp.csv` 的 passage_reward 字段间接推断。

## 三、写作质量

### 3.1 术语一致性问题

- "reward hacking" 在文中中英文混用。建议首次出现时写"奖励黑客（reward hacking）"，之后统一使用"reward hacking"或"奖励利用"。
- "Misaligned Reward" 条件的中文翻译不统一——有时叫"失配奖励"，有时直接保留英文。统一为一种。
- "dense reward" vs "dense reward shaping" vs "原始 Dense Reward"——术语需要统一。

### 3.2 摘要过长

当前摘要约 15 句，对于授课硕论文略长。建议压缩到 8-10 句，去掉过于细节的数字（如"KL 散度 ≈ 19.4 nats"），保留核心发现即可。

### 3.3 图表引用

所有图表引用都指向了 `../results/fig_*.png`，需要确保这些图在最终排版中能正确显示。建议在 LaTeX 中使用 `\includegraphics` 统一管理，并给每张图加上清晰的 caption（当前只有图号，缺少描述性的标题）。

### 3.4 激励机制讨论的语言

§4.1 的机制讨论使用了大量"可能"（约 10 次），虽体现学术诚实但略显重复。建议多样化为：
- "一种可能的解释是…"
- "这与…机制一致"
- "观察到的现象支持以下假说…"
- "需要进一步验证的是…"

### 4.1 Reward 构成占比的额外讨论

表 3.2.1 中，PPO (Sparse) 的"姿态维持"占比高达 55.1%，而 passage_reward 占比 4.1%。这个数据值得在正文中讨论——在完全稀疏的奖励下，PPO 的 reward 几乎全部来自姿态维持（因为 sparse reward 几乎总是 0），这暗示 PPO 的策略退化到了"站着不动"以维持基本姿态奖励的模式。这是一个有趣的额外发现，但当前正文没有讨论。
